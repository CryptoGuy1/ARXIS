v13: set the reject-option threshold off-sample, replace Fig. 3, resync the repo

The 14 September technical review and the supervisor's marked-up screenshots.
Every number that moved was regenerated by a driver; none was edited by hand.

1. Experiment 8 set its confidence threshold at a percentile of the TRAINING
   windows. A paper whose first experiment shows that in-sample estimates
   mislead had set its own operating threshold in sample. The threshold is now
   the q-th percentile over an embargoed calibration band: a contiguous 20%
   tail of each class block, separated from the fitting windows by the same
   20-window embargo the outer holdout uses (retrain/run_reject_option.py).
   Experiment 8 was re-run end to end and every value in Table 12 and Table S9
   changed.

   The findings hold in direction and shrink in size. Support-vector escalation
   repair is 0.0030 -> 0.7111, not 0.0049 -> 0.9283. Clean-window rejection at
   that threshold is 41.2%, not 57.3%. The separation range is +42.4 to -91.6
   points, not +52.0 to -97.0. Two claims are withdrawn: the random forest does
   not reject everything at every threshold, and k-NN rejects fewer than 30% of
   held-out clean windows.

   The driver now imports make() from run_final, so the q = 0 row differs from
   Table 10 only by the reduced fit partition. The Table 12 caption states this
   and quantifies it.

2. Table 13's final column was headed "Anomaly score" and the prose treated it
   as the same quantity as Fig. 5's raw reconstruction errors. It is the
   min-max normalized feature of Eq. 1. Renamed to "Normalized anomaly feature,
   rho-tilde" with both captions stating the scale difference.

3. Raw-fault mode labels named electrical failures the experiment does not
   reproduce. "Open circuit" is now "forced raw zero", described as a low-rail
   proxy; "saturated at rail" is now "high-end clamp". The mechanism claim is
   narrowed to this fitted autoencoder rather than reconstruction detectors in
   general.

4. Fig. 4 drew action 4 as "Emergency shutdown", contradicting the paper's own
   statement that it is deliberately not called that. Now uses Table 4's label.
   Three gates in verify_v13.py check the drawn ladder against the table.

5. Fig. 3 was a five-box flowchart. Replaced by an acquisition schematic with
   real corpus data (retrain/make_fig_setup.py, make setupfig). The v9 figure
   inventory gate carries an explicit RETIRED map rather than being loosened.

6. README target table listed objects from a numbering two revisions old and
   pointed at verify_v11.py. Rewritten against the current objects, plus a note
   that SupervisedDQN is cross-entropy and not RL, and that action 4 is
   Recommend ESD assessment and not an emergency shutdown.

7. Disjoint-support bound called a reference bound rather than a correction,
   with the floor(N/20) convention stated explicitly.

8. Conclusion said "Four findings follow" above five, and its scope paragraph
